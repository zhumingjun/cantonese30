# 30天粤语入门助手（PWA 版）

微信小程序（`cantonese30/`）的**移动端 Web 移植版**，支持：
- 📱 安卓手机浏览器直接使用，可"添加到主屏幕"全屏运行（PWA）
- 📦 用 Capacitor 打包成安卓 APK（见 `APK打包教程.md`）
- 💾 新增**数据备份/恢复**：导出 JSON 备份文件，换手机不丢进度（小程序版没有此功能）

## 快速开始（不打包，直接网页用）

```bash
cd cantonese30-web
npx serve . -l 8080
# 浏览器打开 http://localhost:8080
```

或把整个 `cantonese30-web/` 目录放到任意静态服务器/托管平台。

## 打包安卓 APK

见 **[APK打包教程.md](APK打包教程.md)**（保姆级，含环境安装、打包、安装、常见问题）。

## 功能清单（与小程序版一致 + 优化）

- 📅 首页：今日任务卡、连续打卡徽章、快捷入口、30天总进度、当前阶段、三条铁律
- ✅ 每日任务：Day 1-30 逐日任务勾选（自动保存）、60分钟时间分配、周测日横幅、打卡面板（词数/句数/时长/自评星级/心情）
- 🔤 句型速查：6类分组、搜索、收藏、一键复制
- 🗣 场景对话：5大场景三Tab（必会句/对话跟读/练习指南）、验收标记
- 🎧 听书素材：6类按难度分级（入门/中级/中高级）+ 使用阶段建议
- 📚 学习资源：免费9项+付费3项+听力素材入口
- 📊 我的进度：统计卡、30天日历热力图（点击跳转）、周测标记、终测5项、预期管理
- 💾 **数据备份**：导出/导入 JSON（新增优化）

## 目录结构

```
cantonese30-web/
├── index.html          # 入口（单页应用壳 + 打卡面板 + Tab）
├── app.js              # 全部视图渲染与交互逻辑
├── style.css           # 移动端样式
├── data.js             # 静态数据（30天任务/句型/场景/资源/听书）
├── storage.js          # 本地进度存储（localStorage）+ 备份导出导入
├── manifest.json       # PWA 清单（可安装到主屏幕）
├── sw.js               # Service Worker（离线缓存）
├── icons/              # 应用图标（192/512）
├── capacitor.config.json  # Capacitor 配置（打包 APK 用）
├── package.json        # npm 依赖与脚本
└── APK打包教程.md      # 安卓 APK 打包保姆级教程
```

## 技术说明

- 纯原生 HTML/CSS/JS，**零依赖**（Capacitor 仅在打包 APK 时才需要）
- 进度存浏览器 localStorage，无需后端
- 离线可用（Service Worker 预缓存全部资源）
- 与小程序版功能完全对齐，另新增数据备份/恢复
